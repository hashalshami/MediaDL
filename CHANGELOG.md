# Changelog

All notable changes to MediaDL are documented here.

## 0.1.0 - 2026-09-09

- Initial professional package architecture.
- yt-dlp extraction engine.
- Stable MediaDL models for metadata, formats, progress and results.
- Sync and async downloader APIs.
- Quality presets and audio-only extraction.
- File-size limits and retry policy.
- Proxy and cookies support.
- FFmpeg integration through yt-dlp post-processing.
- CLI for info, format listing and downloads.
- PyPI-ready build configuration and GitHub Actions.
